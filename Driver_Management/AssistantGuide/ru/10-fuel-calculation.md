# Как рассчитывается топливо для поездки

Топливо поездки = **топливо на движение + топливо на простой**.

- **Топливо на движение** = расстояние (км) × расход машины (л/100 км) ÷ 100.
- **Топливо на простой** = часы простоя × расход на простое машины (л/ч).
- **Часы простоя** = время между выездом из гаража и возвращением в гараж минус время движения по маршруту.
  Не бывает меньше 0.

Пример: выезд из гаража 08:00, возвращение 14:00 (6 ч), время движения по маршруту 2 ч, расход на простое 1,2 л/ч
→ 4 часа простоя → 4,8 л на простой, плюс топливо на движение.

## Откуда берутся данные
- **Расстояние и время движения** рассчитываются по адресам поездки через картографический сервис маршрутов.
- **Расход (Consumption, л/100 км)** и **расход на простое (Idle consumption, л/ч)** задаются для каждой машины
  на странице **Cars** (при добавлении или редактировании машины). Расход на простое 0 означает, что топливо на простой
  не считается. Типичные значения: около 0,8–1,5 л/ч для легковой машины, 2–3 л/ч для микроавтобуса.
  При редактировании пустое поле оставляет старое значение; чтобы обнулить, введите 0.

## Почему у поездки в часах простоя стоит «—»
На странице Trips есть колонка **Idle** (простой). «—» означает «нет данных», а не ноль. Так бывает, когда у поездки
нет времени движения по маршруту:
- поездка загружена до появления расчёта простоя, и её расстояние не пересчитывали;
- расстояние оценено по длительности поездки (маршрут не найден или поездка типа Custom Itinerary);
- расстояние введено вручную.
Для таких поездок топливо на простой не считается. Чтобы появились часы простоя, нажмите у поездки кнопку
**Recalculate distance** (значок калькулятора).

## Distance Fallback Speed (страница Fuel Settings)
Если маршрут не найден, расстояние оценивается по длительности поездки с предполагаемой средней скоростью —
**Distance Fallback Speed** (по умолчанию 15 км/ч). Для поездок Custom Itinerary эта оценка также используется
как минимальное расстояние.
- Меняется на странице **Fuel Settings**. Значение больше 0 и не больше 150 км/ч.
- Изменять могут только пользователи с правом управления топливом; остальные видят значение без изменения.
- Изменение влияет только на расстояния, рассчитанные после него. У существующих поездок расстояние остаётся
  прежним, пока их не пересчитают или не загрузят заново.

## Выгрузки
В выгрузке топлива в Excel и в подробной выгрузке CSV есть колонки «Idle Rate (L/h)» и «Idle Hours».
В путевом листе (Waybill) расход топлива уже включает топливо на простой.
